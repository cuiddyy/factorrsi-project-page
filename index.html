01 / The idea

A population that learns
how to specialize.

Different histories can give the same observation different predictive meanings. A single temporal model must fit all of these mechanisms at once. FactorRSI instead evolves a population of factors, each pairing an executable condition with its own prediction model.

An LLM proposes new hypotheses, refines existing factors, and combines parent mechanisms. Sequential factors also carry a temporal input plan. A bounded recursive self-improvement (RSI) controller adapts the search policy using validation evidence.

The population retains its ancestry. Each factor can be traced to the hypotheses and operations that produced it.

RSI policy adaptation

Candidates are trained and evaluated before entering the population. The RSI controller changes the search policy while keeping labels, temporal cutoffs, and evaluation rules fixed.
